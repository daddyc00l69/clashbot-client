========================================================================
CLASHBOT AI — CLIENT DASHBOARD INSTRUCTIONS
========================================================================

Welcome to ClashBot AI! All heavy bot logic and AI combat intelligence
run securely on the server. Your client is a sleek, lightweight controller.

FIRST TIME SETUP:
- Double-click `install.bat` (or `run_bot.bat`).
- It will automatically install requirements and launch the app.

HOW TO RUN:

1. START YOUR ANDROID EMULATOR:
   - Open BlueStacks, LDPlayer, MuMu Player, or Nox.
   - Start Clash of Clans.
   - Ensure ADB is enabled in emulator settings:
     * BlueStacks: Settings -> Advanced -> Android Debug Bridge -> ON
     * LDPlayer  : Settings -> Other Settings -> ADB Debug -> Local / Remote
     * MuMu      : Settings -> Basic -> ADB -> ON

2. LAUNCH CLASHBOT AI:
   - Double-click `run_bot.bat`.
   - Enter your license key (e.g. CB-XXXXX-XXXXX-XXXXX-X) in the clean login dialog.
   - Your hardware ID is silently verified with the server.

3. CONTROL & MONITOR:
   - Click "▶ Start Bot" to begin autonomous combat intelligence on the cloud server.
   - Watch live loot stats (Gold, Elixir, Dark Elixir, Attacks) update in real-time.
   - View live server actions streamed directly to your execution feed.
   - Click "⏸ Pause" or "⏹ Stop Bot" anytime.
